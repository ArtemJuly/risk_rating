# Калькулятор риск-рейтинга

Инструмент для автоматического расчёта риск-рейтинга инвестиционных фондов (1–7).  
Рейтинг отражает максимально ожидаемые потери инвестора за год.

---

## Что такое риск-рейтинг

Итоговый рейтинг от 1 до 7. Чем выше — тем выше риск:

| Рейтинг | Ожидаемые потери |
|---------|-----------------|
| 1       | 0 – 5%          |
| 2       | 5 – 10%         |
| 3       | 10 – 20%        |
| 4       | 20 – 30%        |
| 5       | 30 – 50%        |
| 6       | 50 – 70%        |
| 7       | > 70%           |

**Как считается итоговый рейтинг:**

```
Компоненты → Категория → Итог
───────────────────────────────────────────────
VaR         ─┐
              ├─ Количественный (max) ─┐
Стресс-тест ─┘                        ├─ max ─ Итоговый рейтинг
                                       │
Кредитный риск  ─┐                    │
                  ├─ Качественный (max)┘
Процентный риск ─┘
```

Итоговый рейтинг = максимум из всех компонент (консервативный подход).

## Как запустить расчёт

### Один раз: установить окружение

```bash
# Клонировать репозиторий
git clone <repo_url>
cd calculator

# Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows

# Установить зависимости
pip install --upgrade pip
pip install -e .
pip install pandas numpy openpyxl plotly pyyaml scikit-learn
```

### Каждый раз: запуск расчёта

```bash
# Активировать окружение (если не активировано)
source .venv/bin/activate

# Запуск — заменить ISIN на нужный
python run.py RU000A1002S8
```

Скрипт:
1. Загружает NAV и состав портфеля из `data/products/RU000A1002S8.xlsx`
2. Считает все 4 компонента риска
3. Печатает результат в терминал
4. Сохраняет `risk_rating_RU000A1002S8.html` и открывает в браузере

**Если не нужен браузер:**
```bash
python run.py RU000A1002S8 --no-browser
```

## Формат данных

### `data/products/{ISIN}.xlsx`

Файл для каждого фонда. Должен содержать лист `nav` (обязательно) и лист `holdings` (если фонд облигационный).

**Лист `nav`** — история СЧА:

| Date       | NAV              |
|------------|-----------------|
| 2022-01-10 | 331 553 946,12   |
| 2022-01-11 | 332 100 000,00   |

> Числа с пробелами-разделителями тысяч и запятой как десятичным знаком — ок, парсится автоматически.

**Лист `holdings`** — состав портфеля на последнюю дату:

| ISIN         | Weight |
|--------------|--------|
| RU000A103X00 | 0.05   |
| RU000A104AB1 | 0.03   |

> `Weight` — доля в портфеле (0.0 – 1.0), сумма весов ≈ 1.

### `data/reference/bonds_db.xlsx`

Справочник облигаций. Лист `dataBonds`:

| ISIN         | CreditExpert | CreditAkra | CreditNKR | Duration |
|--------------|-------------|-----------|----------|---------|
| RU000A103X00 | AAA          |            |           | 1.85     |
| RU000A104AB1 |              | AA+        |           | 2.40     |

- `CreditExpert / CreditAkra / CreditNKR` — рейтинг от агентства (берётся первый непустой)
- `Duration` — дюрация Маколея в годах (заполняется вручную)

## Как добавить новый фонд

1. Создать `data/products/{ISIN}.xlsx` с листами `nav` и `holdings`
2. Для каждого холдинга заполнить строку в `bonds_db.xlsx` — рейтинг и дюрацию
3. Запустить: `python run.py {ISIN}`

## Описание компонент риска

### VaR (Value at Risk)
- Исторический VaR на уровне доверия 95%
- Дневной VaR аннуализируется по правилу √252
- Вход: `nav_series` из Portfolio

### Стресс-тест (бета-факторный)
- Вычисляет бету фонда к индексу RGBITR на историческом периоде
- Применяет бету к реальному шоку индекса (по умолчанию: RGBITR июль–декабрь 2014, −14.4%)
- Вход: `nav_series` + исторические данные индекса из `data/market/rgbitr.xlsx`

### Кредитный риск
- Для каждого холдинга берёт рейтинг из `bonds_db.xlsx` (Expert RA → АКРА → НКР)
- Конвертирует в СКК (1–6) по YAML-шкале
- Считает средневзвешенный СКК → маппит в рейтинг 1–7
- Холдинги без рейтинга исключаются из расчёта

### Процентный риск
- Читает дюрацию Маколея из колонки `Duration` в `bonds_db.xlsx`
- Считает средневзвешенную дюрацию портфеля
- Строит 7-бинную шкалу на основе эталонных облигаций из `reference_bonds.yaml`

## Как добавить новый компонент риска

1. Создать файл в `risk_module/quantitative/` или `risk_module/qualitative/`
2. Реализовать класс с атрибутом `name` и методом `calculate(portfolio) → ComponentResult`
3. Добавить компонент в список в `run.py`

Пример:
```python
class MyNewComponent:
    name = "MyRisk"

    def calculate(self, portfolio: Portfolio) -> ComponentResult:
        # ... логика ...
        return ComponentResult(
            component=self.name,
            rating=3,
            category="qualitative",   # или "quantitative"
            loss_pct=0.15,            # опционально
            meta={},
        )
```

`RiskEngine` автоматически включит новый компонент в агрегацию — менять `engine.py` не нужно.
